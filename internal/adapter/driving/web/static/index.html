    Run a command on a machine
    
    
    Runs one command with viper ssh on a machine or on every machine of a group, as your user on the machine. The output is on the page Runs. Do not write secrets into the command: it is in the run and in the process list of this computer, and viper hides only the secrets of your settings. A command that runs long holds the machine; end it with Cancel, or start it with timeout 60.
