Gespräche mit den Rechnern von bedrock-eu-guard-compose brauchen einen eigenen Schlüssel, den „Operator“. Er gehört nur Ihnen und bleibt auf diesem Rechner.
  1. Die Seite legt den Schlüssel an (viper nats init).
  2. Der Server der Gruppe trägt ihn ein.
  3. Danach sind alle Gespräche da.
Als Operator anmeldenMit einer Frage an einen Rechner behelfen
Ohne Schlüssel geht nur Senden über einen Rechner der Gruppe (ssh), ohne Mitlesen.
